# Детальная карта проекта FuelMaster

Это подробный обзор структуры и ключевых файлов проекта FuelMaster.

## 📂 Корень проекта

- `pubspec.yaml`: Определяет все зависимости проекта (пакеты Flutter/Dart), версию приложения, а также подключаемые ресурсы (шрифты, изображения).
- `firebase.json`, `firestore.rules`: Файлы конфигурации для интеграции с Firebase (база данных, правила безопасности).
- `l10n.yaml`: Конфигурация для локализации (перевода) приложения на разные языки.
- `analysis_options.yaml`: Правила для статического анализатора кода Dart, помогает поддерживать код в чистоте и избегать ошибок.
- `.gitignore`: Список файлов и папок, которые должны быть проигнорированы системой контроля версий Git.
- `README.md`: Описание проекта.

---

## 📂 lib — Основная логика приложения (Dart)

Это главная папка, где находится весь код на языке Dart.

### 📄 Основные файлы экранов:
- `main.dart`: **Точка входа в приложение.** Здесь инициализируются Firebase, провайдеры состояния и запускается главный экран.
- `splash_screen.dart`: Экран загрузки, который видит пользователь при первом запуске.
- `onboarding_page.dart`: Страницы-инструкции для новых пользователей.
- `registration_page.dart`: Экран регистрации и входа в систему через Firebase Authentication.
- `main_menu_page.dart`: Главное меню, откуда осуществляется навигация по основным разделам.
- `car_list_page.dart`: Отображает список автомобилей пользователя.
- `car_info_page.dart`: Показывает детальную информацию о выбранном автомобиле.
- `fuel_calculator_page.dart`: **Ключевой экран.** Здесь находится калькулятор расхода топлива.
- `history_page.dart`: Показывает историю расчетов с графиками.
- `settings_page.dart`: Настройки приложения (тема, язык и т.д.).
- `theme.dart`: Определяет цветовые схемы и стили для светлой и темной тем приложения.
- `widgets.dart`: Содержит общие, переиспользуемые виджеты (устаревший подход, лучше использовать папку `widgets`).
- `firebase_options.dart`: Автоматически сгенерированный файл для конфигурации Firebase.

### 📂 l10n/ — Локализация
- `app_en.arb`, `app_ru.arb`: Файлы с переводами всех текстовых строк на английский и русский языки.
- `app_localizations.dart`, `app_localizations_en.dart`, `app_localizations_ru.dart`: Автоматически сгенерированные Dart-классы для доступа к строкам локализации.

### 📂 providers/ — Управление состоянием
- `app_settings_provider.dart`: Управляет состоянием настроек приложения (тема, язык).
- `car_provider.dart`: Управляет состоянием списка автомобилей (добавление, удаление, обновление).
- `history_provider.dart`: Управляет состоянием данных истории расчетов.

### 📂 services/ — Взаимодействие с внешними сервисами
- `location_service.dart`: Сервис для работы с геолокацией устройства.
- `map_page.dart`: Экран, отображающий карту (вероятно, с использованием Yandex MapKit).

### 📂 utils/ — Вспомогательные утилиты и классы
- `database_helper.dart`: **Очень важный файл.** Управляет локальной базой данных SQLite (создание таблиц, CRUD-операции).
- `preset_data_loader.dart`: Загружает предустановленные модели автомобилей из `assets/cars.csv`.
- `initial_data.dart`: Логика для первоначального заполнения базы данных.
- `weather_service.dart`: Сервис для получения данных о погоде с внешнего API. **Содержит API-ключ.**
- `deepseek_service.dart`: Сервис для взаимодействия с AI-моделью DeepSeek. **Содержит API-ключ.**
- `fuel_calculation_service.dart`: Основная логика для выполнения расчетов топлива.
- `history_manager.dart`: Управляет сохранением и загрузкой записей истории.
- `history_display_service.dart`: Логика, связанная с отображением истории.
- `ad_manager.dart`, `yandex_ads_channel.dart`: Классы для управления показом рекламы Yandex.
- `app_initializer.dart`: Логика, выполняемая при инициализации приложения.
- `constants.dart`: Глобальные константы приложения.
- `logger.dart`: Настройка логгера для отладки.
- `utils.dart`: Общие вспомогательные функции.
- **📂 models/**
    - `car_data.dart`: Модель данных, описывающая структуру объекта "автомобиль".

### 📂 widgets/ — Переиспользуемые виджеты
- `gradient_background.dart`: Виджет для создания градиентного фона.
- `gradient_button.dart`: Кастомная кнопка с градиентом.
- `gradient_text.dart`: Текст с градиентной заливкой.
- `license_plate_widget.dart`: Виджет для отображения стилизованного номерного знака.
- `weather_display_widget.dart`: Виджет для отображения информации о погоде.

## 📂 assets — Статические ресурсы

- `cars.csv`: CSV-файл с базой моделей автомобилей для первоначального заполнения.
- `loading_animation.json`: Анимация загрузки в формате Lottie.
- `fuelmaster_logo.png`, `launch_image.png`, и т.д.: Графические ассеты.
- **📂 2.0x/, 3.0x/, 4.0x/**: Разные разрешения изображений для экранов с высокой плотностью пикселей.
- **📂 car_brands/**: Изображения логотипов всех марок автомобилей.
- **📂 fonts/**: Файлы шрифтов, если используются кастомные.
- **📂 icon/**, **📂 logo/**, **📂 images/**: Другие графические ресурсы.

## 📂 android — Нативный проект Android

- `build.gradle.kts`: Корневой файл сборки Gradle, управляет зависимостями всего Android-проекта.
- `settings.gradle.kts`: Настройки Gradle, определяет, какие модули включены в сборку.
- `gradle.properties`: Свойства для конфигурации Gradle (например, версии, параметры JVM).
- `keystore.properties`: **Секретный файл.** Содержит данные для подписи релизной версии приложения.
- **📂 app/** — Основной модуль приложения
    - `build.gradle.kts`: Конфигурация сборки для модуля `app`. Здесь подключаются зависимости SDK (Firebase, Yandex Ads).
    - `google-services.json`: Файл конфигурации Firebase для Android.
    - `proguard-rules.pro`: Правила для обфускации (сжатия) кода в релизной сборке.
    - **📂 src/main/**
        - `AndroidManifest.xml`: "Паспорт" Android-приложения. Определяет разрешения (доступ в интернет), компоненты, ID рекламных сетей.
        - **📂 kotlin/com/example/fuelmaster/**
            - `MainActivity.kt`: Основной `Activity` на Kotlin, который запускает Flutter. Здесь реализована интеграция с Yandex Mobile Ads через MethodChannel и PlatformViews.
            - `MainApplication.kt`: Класс приложения, используется для инициализации сервисов до запуска `MainActivity` (например, Yandex MapKit).
        - **📂 res/** — Ресурсы Android-приложения
            - **📂 drawable***/**: Изображения, иконки, фоны.
            - **📂 layout/**: XML-файлы разметки для нативных Android-элементов (например, `native_ad_layout.xml` для рекламы).
            - **📂 mipmap***/**: Иконки приложения для разных разрешений экрана.
            - **📂 values***/**: XML-файлы со значениями (цвета, строки, стили).
            - **📂 xml/**: Другие конфигурационные XML-файлы.
- **📂 gradle/wrapper/**: Содержит файлы для запуска конкретной версии Gradle, обеспечивая консистентность сборки.
