## Источник

**中国汽车能源消耗量查询** — государственная система Министерства
промышленности и информатизации КНР (`yhgs.miit.gov.cn`). Производитель обязан
сдать данные по каждому одобренному типу транспортного средства, министерство
публикует их ежемесячно. Это первоисточник, а не пересказ.

API отдаёт машиночитаемый JSON. Использованы два реестра:

| Реестр | Записей | Что внутри |
|---|---|---|
| `queryList` (能耗标识) | 105 242 | Расход по городу / пригороду / смешанный цикл (WLTC, NEDC, CATC), мощность, объём, трансмиссия, класс ТС |
| `queryNewList` | 32 767 | Фазы WLTC по отдельности, кВт·ч, CO2, запас хода, снаряжённая масса |

Выкачано полностью: **686 страниц, 138 009 записей, 0 ошибок**. Сбор идёт в
несколько потоков с паузой и повторными попытками; уже скачанные страницы
сохраняются постранично, поэтому сбор можно прервать и продолжить.

## Инструменты (tools/)

| Файл | Назначение |
|---|---|
| `miit_fetch.py` | Сбор реестра: `--all` (весь реестр), `--brand`, `--producer`, `--merge`. Возобновляемый |
| `miit_import.py` | Преобразование сырых записей в каталог: марка, модель, класс, нормы, происхождение |
| `miit_aliases.py` | Сопоставление китайских названий с рыночными и инвентаризация моделей |
| `build_catalog.py` | Сборка `assets/cars.csv` из базового снимка и данных МИИТ (`--dry-run` для отчёта) |

Вспомогательные данные:

* `data/alias_candidates.csv` — кандидаты соответствий (марка и модель, как их
  знают на рынке RU/KZ, и вероятные китайские написания);
* `data/alias_verified.csv` — **только те соответствия, что подтвердились
  данными** (263 из 257 кандидатов; 32 написания не найдены и в таблицу не попали);
* `data/sub_brands.csv` — суббренды, которые в реестре идут под чужим
  производителем (Tank, WEY, Ora — внутри Great Wall; Jetour, Exeed — внутри Chery);
* `data/miit_models_top.md` — топ моделей по каждой марке для ручной сверки;
* `data/cars_base.csv` — чистый базовый каталог, от которого идёт сборка.

## Как воспроизвести

```bash
python tools/miit_fetch.py --registry both --all --workers 3
python tools/miit_import.py
python tools/miit_aliases.py
python tools/build_catalog.py --dry-run     # отчёт, файл не меняется
python tools/build_catalog.py --replace-cn  # записать assets/cars.csv
flutter analyze && flutter test
```

## Что нашлось в существующей базе

**Нормы по китайским маркам были шаблонными.** 122 строки содержали всего 22
различных пары значений, причём 55 строк (45 %) — одну и ту же пару 8,9 / 7,0:
Haval Jolion, Geely Coolray, Changan UNI-T, Jetour X70, Omoda C5, Kaiyi E5
показывали одинаковый расход. Для сравнения: во всей остальной базе 2 669
различных пар на 11 475 строк, самая частая встречается 82 раза.

Строки, для которых реестр дал настоящую норму, заменены на данные
производителя: **удалено 82 шаблонные строки**. Jolion теперь 2 строки с
реальной нормой производителя вместо выдуманной.

## Ошибка в приложении, найденная этой работой

Каталог читался так: `CsvToListConverter(shouldParseNumbers: false)` — без
указания перевода строки, а по умолчанию ожидается `\r\n`. Файл, записанный с
одиночными `\n`, разбирался как **одна строка**: приложение удаляло старый
каталог, вставляет ноль строк и молча остаётся без каталога. Сейчас перевод
строки определяется по файлу, перед пустым импортом добавлена явная проверка,
написана регрессия (`test/preset_reimport_test.dart`, тест «разбор каталога не
зависит от перевода строки»).

## Честные оговорки

1. **Нормы МИИТ — китайская спецификация.** Для некитайских марок (Audi, BMW,
   Toyota) эти данные в каталог намеренно **не подмешивались**: комплектации для
   РФ и КЗ отличаются, и выдавать чужую норму за свою нельзя. Такие записи
   лежат в `data/catalog_miit.csv` (33 057 строк) и включаются ключом
   `--include-foreign`.
2. **Топливо, где реестр молчит.** В реестре 能耗标识 поля топлива нет: есть
   только «традиционное топливо / гибрид / электро». Для легковых принято
   бензин, для грузовых, автобусов и фургонов — по рабочему объёму; в колонке
   происхождения это записано словами («принято: дизель по классу и объёму»,
   25 449 строк). Перекрёстная сверка со вторым реестром по коду типа ТС
   уточняет топливо точно (汽油/柴油) для 2 761 строки.
3. **Второй реестр почти не даёт пар «город/трасса»** — только смешанный цикл.
   Такие строки (45 033) в каталог не вошли: калькулятору нужны обе нормы.
   При необходимости их можно добавить отдельным слоем.
4. **Сопоставление названий неполное.** Часть моделей осталась под китайскими
   названиями (например 瑞虎, 风云2) — это честнее, чем подставить похожее имя.
   Полный список таких марок и моделей — в `data/miit_models_top.md`.
